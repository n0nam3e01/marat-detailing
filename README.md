# MARAT DETAILING — сайт студии

Одностраничный сайт детейлинг-студии в Астане. Тёмная премиум-тема,
двуязычие (Русский / Қазақша), адаптив, карта и кнопки соцсетей.
Чистая статика — HTML/CSS/JS, без сборки и сервера.

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка страницы |
| `styles.css` | Оформление (тёмная тема, адаптив) |
| `script.js`  | Логика, переводы и **все настройки вверху файла** |

## Что заполнить (быстрый список)

Откройте `script.js` — в самом верху блок `CONFIG`:

```js
const CONFIG = {
  instagram: "https://www.instagram.com/marat_detailing/", // уже заполнено
  whatsapp: "",   // номер только цифрами, напр. "77001234567"
  phone:    "",   // напр. "+7 700 123 45 67"
  tiktok:   "",   // полная ссылка на TikTok
  twogis:   "",   // ссылка на карточку студии в 2ГИС
  address:  "",   // точный адрес, напр. "Астана, ул. Кабанбай батыра, 00"
  mapQuery: "Астана, Казахстан", // что показывать на карте без точного адреса
};
```

- Кнопки контактов без ссылки показываются **неактивными** (пунктир).
  Как только впишете номер/ссылку — станут кликабельными.
- Как только заполните `address` — карта покажет точную точку, а в блоке
  контактов появится адрес.

## Форма заявки → WhatsApp

Блок «Оставьте заявку» собирает **имя + телефон** (и, по желанию, услугу) и
открывает WhatsApp владельца с уже готовым текстом заявки — клиенту остаётся
нажать «Отправить». Сайт статический, поэтому это самый надёжный способ без сервера.

- Чтобы форма работала, **обязательно заполните `whatsapp` в `CONFIG`** (номер только
  цифрами, например `77001234567`). Пока номер пустой, форма покажет подсказку об этом.
- Тексты FAQ и формы — в `script.js` → `I18N` (ключи `lead.*` и `faq.*`), на двух языках.

## Логотип

Шапка и футер уже настроены на файл логотипа. Просто положите картинку
логотипа рядом с `index.html` под именем **`logo.png`** (можно и `logo.svg` —
тогда поправьте `src` в двух местах `index.html`).

- Как только файл появится — он автоматически заменит текстовую надпись.
- Пока файла нет, показывается аккуратная надпись «МАРАТ ДЕТЕЙЛИНГ» — ничего не ломается.
- Лучше горизонтальный логотип на прозрачном фоне (PNG с прозрачностью), высота отображения ~38px.

Фирменный цвет сайта — **жёлтый** (`--accent` в `styles.css`, значение `#ffc400`).

## Фото работ

Плитки в разделе «Работы» пока — стильные заглушки. Чтобы вставить фото,
добавьте в плитку `<img>` внутрь `<figure class="work-tile">` (фон-градиент
уберётся картинкой). Идеальный формат — квадрат/вертикаль, тёмные снимки.

## Хостинг

Статика — подойдёт любой бесплатный вариант:

- **Vercel / Netlify / Cloudflare Pages** — перетащите папку или импортируйте репозиторий.
- **GitHub Pages** — залейте файлы, включите Pages в Settings → Pages.

Локально просто откройте `index.html` в браузере (карта и шрифты
подтянутся из интернета).

## Язык

По умолчанию — русский. Переключатель RU / ҚАЗ в шапке; выбор
запоминается в браузере. Тексты обоих языков — в `script.js` → `I18N`.

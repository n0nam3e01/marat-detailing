# MARAT DETAILING Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enlarge all action buttons and refresh the existing dark detailing website with restrained motion inspired by Almaz Tour.

**Architecture:** Keep existing static HTML, CSS, configuration and bilingual UI. Update existing component styles directly; place progressive motion enhancements in a separate script with no network dependencies. Work on an isolated GitHub branch, retaining the upstream base SHA for rollback.

**Tech Stack:** HTML, CSS, vanilla JavaScript, Node, Playwright/Chromium.

**Spec:** `docs/superpowers/specs/2026-10-23-redesign-design.md`

## Global Constraints

- Preserve background #101110, surfaces #1a1b19, text #f6f6f2, muted #b7b8b2 and accent #f4ce45.
- Preserve Manrope, photographs, RU/ҚАЗ, contacts and WhatsApp submission.
- Action buttons at least 52–56 px tall; language/menu controls at least 44×44 px.
- Respect reduced motion; content remains available without JavaScript.
- Do not merge into main or publish production as part of this change.

## Review Focus

- Long Kazakh labels at 320 px must wrap without horizontal overflow.
- Keyboard activation of links must keep native navigation and visible focus.
- Reduced-motion preference changes must stop decorative effects and reveal content.
- Disabled JavaScript must leave all sections readable and links usable.
- Floating WhatsApp must not cover final mobile footer actions.
